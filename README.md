 # Сheck In – Сервис проверки посещаемости

Сервис для учета посещаемости студентов в университете. Позволяет студентам отмечаться через QR-код, указывать причины пропусков, старостам просматривать статистику по группе, преподавателям управлять посещаемостью и причинами, а деканам получать справки и отчеты.
